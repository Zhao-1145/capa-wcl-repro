# Reproducibility package

**Manuscript.** "Range Errors as Uniform Phase Rotations in Continuous Aperture
Arrays: Consequences for Near-Field Channel Estimation."
Submitted to *IEEE Wireless Communications Letters*.
Author: Yijie Zhao (Xidian University), ORCID 0009-0007-9222-3234.

This package contains the manuscript source, the supplementary source, the
full computational pipeline, trained model checkpoints, and the archived
result files behind every quantitative claim.

## What a reviewer can do here

```
bash run          # or: python verify_paper.py
```

`run` executes `verify_paper.py`, which recomputes every quantitative claim in
the manuscript from the archived JSON files and compares it against the numbers
as typeset in the paper. Expected output ends with `pass 301 / 301` and
`VERDICT: PASS`; exit code 0. It uses the **Python standard library only** --
no NumPy, no network, no GPU. Runtime: a few seconds.

## Scope -- please read

This capsule reproduces the **numbers-to-archive reconciliation** and ships the
code that produced them. Specifically:

| Directory | Contents |
|---|---|
| `src/` | Full pipeline: `train.py`, `baselines.py`, `capa_lib.py`, `compute_crb.py`, `make_data.py`, `make_figs.py`, holdout/reevaluation scripts |
| `models/` | Trained checkpoints (`eq_cls_s0/s1/s2_best.pt`) |
| `runs/` | Training run records (config + result JSON) |
| `figs/`, `figs_transfer256/`, `figs_transfer512/` | Archived result JSON behind every reported number, plus figure sources |
| `audit_evidence/` | Independent recalculation evidence |
| `data/` | Small holdout payload shipped with the package |
| `results/` | Written by `run` (log of the verification) |

**What is NOT bundled:** the large training datasets (`tr_M256`, `tr_M128`,
`ev_M512`, on the order of gigabytes). They are regenerated by `src/make_data.py`
with fixed seeds, or supplied separately. Consequently, `run` does **not**
retrain the models: retraining from scratch took about 45 minutes per model on a
CPU-only machine (Intel Core Ultra 5 125H, no CUDA), and the multi-seed study took
8.59 hours. The shipped checkpoints allow evaluation to be re-run without training.

## Environment

`verify_paper.py` and the LaTeX/ASCII/reference-integrity checks need only the
Python standard library. `check_figs.py` and `make_figs.py` additionally need
`numpy` and `matplotlib` (Agg backend). See `requirements.txt`; a CPU-only
`python:3.11-slim` image is provided in `environment/Dockerfile`.

## Checks included

```
python verify_paper.py         # every reported number vs archived JSON -> 301/301
python check_figs.py           # figure presence / geometry / legibility (numpy, matplotlib)
python audit_format.py         # IEEE WCL format checks
python latex_static_check.py   # LaTeX static checks
python zcode_ref_integrity.py  # bibliography integrity (25 entries)
python scan_nonascii.py        # manuscript source is pure ASCII
```
